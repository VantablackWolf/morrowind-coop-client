# Morrowind Co-op — client and server binaries

TES3MP (a hard fork of OpenMW 0.47) ported onto **OpenMW 0.51.0**.

The binaries are published as **release assets**, not as files in this tree.
See [Releases](../../releases).

## What is in the archive

```
client/   tes3mp.exe, tes3mp-server.exe, tes3mp-browser.exe, dependencies,
          and a stock structural openmw.cfg
server/   server scripts and an empty world skeleton
```

The mods are not here and never will be — they belong to their authors and are
downloaded from Nexus by the installer.

## Licence

OpenMW and TES3MP are GPLv3. These are binaries built from a modified source
tree; under the GPL the corresponding source is available to anyone who receives
them. Ask and you will be given it.

## Which archive goes with which modlist

Each release is pinned by hash in the Wabbajack modlist that uses it. If you are
installing the modlist you do not need to download anything here by hand.
